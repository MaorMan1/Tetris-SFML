# Tetris Remake (SFML + C++) by Maor Man - 2025

A polished and modern C++ remake of the classic Tetris game using the SFML library.  
Includes animations, custom UI, music, effects, and more!

---

## Features

- Seven Tetris pieces (I, O, T, S, Z, J, L)
- Line-clearing animation
- Countdown and gravity mechanics
- Fire trail effect on fast drop
- Ghost piece
- Score system and Leaderboard
- Background music and sound effects
- Menu system (Main, About, Leaderboard)
- Pixel-art UI buttons (Retry, Pause, Mute, Back)
- Polished game over screen

---

## Requirements

- CMake (>= 3.10)
- SFML 3 (via vcpkg)
- Ninja (recommended for faster builds)
- Visual Studio 2022 or any C++17 compatible compiler

---

## How to Build

Make sure you have [vcpkg](https://github.com/microsoft/vcpkg) installed and integrated:

```bash
git clone https://github.com/microsoft/vcpkg.git
./vcpkg/bootstrap-vcpkg.bat
```
